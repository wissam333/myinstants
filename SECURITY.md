# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please **do not open a public issue** for security problems. Instead, use GitHub's
private vulnerability reporting:

1. Go to this repository: **Security → Report a vulnerability**.
2. Describe the issue, the affected endpoint/function, and a minimal reproduction.

I aim to acknowledge reports within 48 hours and will publish a fix as soon as
possible once a valid report is confirmed.
